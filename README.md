# Proyecto de Consolidación PC6

Este proyecto corresponde a la actividad de consolidación PC6, enfocada en la predicción de series temporales utilizando modelos profundos.

El objetivo principal es aplicar los conceptos aprendidos sobre redes recurrentes y modelos de deep learning para construir modelos de predicción de la variable `Sales` del dataset Rossmann.

## Objetivo del proyecto

Construir y evaluar modelos de predicción para:

- Tienda 1 del dataset Rossmann
- Tienda 2 del dataset Rossmann

El propósito es maximizar el coeficiente de determinación `R²` en el conjunto de prueba, buscando obtener un resultado lo más cercano posible a `1`.

## Enfoque general

Para el desarrollo del proyecto se toma como base el notebook de Rossmann trabajado en clase. A partir de este, se desarrollan diferentes versiones del modelo, incorporando variables históricas y variables exógenas relevantes para la predicción de ventas.

## Entregable

El entregable consiste en un archivo `.zip` con dos notebooks:

- Un notebook para la tienda 1
- Un notebook para la tienda 2

Cada notebook contiene el proceso de preparación de datos, construcción del modelo, entrenamiento, evaluación y análisis de resultados.
